# Linux File Permissions
- Linux file permissions control access to files and directories in the system.
- There are 3 types of permissions
	- **Read (`r`)** - You can read the contents of a file
	- **Write (`w`)** - You can modify the contents of a file
	- **Execute (`w`)** - You can run/execute a file
- Permissions can be assigned to 3 classes of users
	- **Owner**
	- **Groups**
	- **Others**

## Importance of File Permissions
1. **Security** - File permissions protect sensitive data by controlling who can access, modify, or execute files.
2. **Data Integrity** - Prevents accidental or malicious changes to files by restricting write access.
3. **User Management** - Enables system admin to assign access rights to different users or groups.
4. **System Stability** - Maintains system stability by preventing unauthorized users from executing critical system files.
5. **Compliance** - Helps security
