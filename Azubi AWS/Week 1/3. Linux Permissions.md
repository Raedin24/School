# Linux File Permissions
- Linux file permissions control access to files and directories in the system.
- There are 3 types of permissions
	- **Read (`r`)** - You can read the contents of a file
	- **Write (`w`)** - You can modify the contents of a file
	- **Execute (`w`)** - You can run/execute a file
- Permissions can be assigned to 3 classes of users
	- **User**
	- **Groups**
	- **Others**

## Importance of File Permissions
1. **Security** - File permissions protect sensitive data by controlling who can access, modify, or execute files.
2. **Data Integrity** - Prevents accidental or malicious changes to files by restricting write access.
3. **User Management** - Enables system admin to assign access rights to different users or groups.
4. **System Stability** - Maintains system stability by preventing unauthorized users from executing critical system files.
5. **Compliance** - Helps organizations meet security and privacy regulations by ensuring only authorized personnel can access sensitive data.

# Changing File Permissions in Linux
## Understanding File Permissions
- Permissions are always set in the order of *read, write, execute* ie. *rwx* .
- The permissions are further set in order of *User, Groups, Others*
- Combining this sequence, we get 3 sets, `rwxrw-r--`
	- First set of `rwx` indicates read, write and execute permissions are set for the user
	- Second set indicates read and write permissions are set for the group, with the `-` showing that group doesn't have execute permissions
	- Third set shows that others only have read permissions

>2. Files are created with `-rw-rw-r--` permissions by default
>3. Directories are created with `drwxrwxr-x` permissions by default.
>4. Use the `ls -l` or `ll` command to display permissions of files


## Changing Permissions with `chmod`
There are 2 ways of changing file permissions with `chmod`. 
1. **Absolute (Numeric) Mode**: Specify the permissions using numeric values. `r` is **4**, `w` is **2**, and `x` is **1**. You can add these values to set multiple permissions as a three-digit number.
	eg `chmod 644`  - 6 (4+2) for users, 4 for groups, 4 for groups
